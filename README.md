## MOVIE WEB 
- *Movie web xây dựng bằng ReactJS frontend và NodeJs Express backend*
- *Chức năng xem danh sách và chi tiết phim*
- *Nhiều thể loại từ TV Seri và Movie*

!['img'](/movie-frontend//public/img.png)

### Api Key
```bash
    https://developer.themoviedb.org/docs/getting-started # Truy cập TMDB để lấy Api Key
```

### Run client
```bash
    cd movie-frontend
    npm run dev
```

### Run server
```bash
    cd movie-backend
    node server.js
```
